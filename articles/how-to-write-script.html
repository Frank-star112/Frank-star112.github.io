小红书视频脚本怎么写？5种类型模板

阅读约 6 分钟 · 拍视频前先看这篇

视频火不火，脚本占一半。好脚本不是文采，是结构：开头 3 秒留人、中间给价值、结尾引导互动。下面按类型给你可直接套的结构。

一、所有类型的共同地基：前3秒钩子

用户划走只需要 0.3 秒。前 3 秒必须抛出一个「和我有关」或「反常识」的点。常用钩子：

  • 别划走！{kw}这件事我后悔没早知道
  • 谁懂啊，{kw}居然还能这样
  • {kw}到底值不值？实测给你看

二、五种类型脚本结构

口播类

  1. 反常识观点戳痛点
  2. 抛真相引发好奇
  3. 核心方法分 1/2/3 步
  4. 金句收尾
  5. 引导评论互动

教程类

  1. 结果前置（你能收获什么）
  2. 准备清单
  3. 逐步演示
  4. 易错点提醒
  5. 成果展示+行动号召

种草类

  1. 场景痛点
  2. 产品出现制造惊艳
  3. 真实体验三连
  4. 适合/不适合谁
  5. 下单引导

测评类

  1. 开宗明义测什么
  2. 参数过一遍
  3. 维度打分
  4. 一周真实反馈
  5. 推荐 or 劝退

Vlog类

  1. 氛围定调开场
  2. 日常快剪+字幕
  3. 小转折/小确幸
  4. 感悟升华
  5. 温柔收尾
脚本不用写逐字稿，把「钩子 + 分镜要点 + 结尾引导」列清楚就够拍了。越细越容易卡，先动起来。

三、写完做一件事：念一遍

把脚本大声念出来，哪里拗口就在哪里改。口语化比书面语完播率高得多。
