小红书简介怎么写？4类人设模板

阅读约 4 分钟 · 一句话立住账号调性

用户刷到你，先看封面标题，点进主页，第二眼就是简介。简介写得好，关注转化率能差好几倍。它不用长，但必须让人「一眼知道你是谁、为什么关注你」。

一、好简介的「三要素」

你是谁

身份 / 领域，一句话说清定位，比如「5年护肤配方师」。

你能给什么

关注你能得到什么价值，比如「只讲看得懂的成分」。

一句口号

记忆点，比如「不交智商税」。

标签收尾

用 2-3 个标签点明赛道，方便检索和归类。

二、4类人设模板（直接套）

1. 专业靠谱型

适合知识、测评、行业号。结构：身份+成绩 / 你提供什么 / 口号。例：「十年室内设计师｜帮 1000+ 人搞定小家｜少花钱住得舒服」。

2. 亲切邻家型

适合日常、母婴、生活号。结构：真实身份+日常+陪伴感。例：「96年沪漂打工人｜下班做饭治愈自己｜一起慢慢变好」。

3. 毒舌真实型

适合避坑、吐槽、测评号。结构：犀利观点+帮避坑。例：「专拆网红智商税｜买错的比买对的还多｜关注少踩坑」。

4. 文艺治愈型

适合摄影、手作、独居号。结构：氛围+价值观。例：「记录普通日子里的光｜慢一点也没关系｜谢谢你来看」。

三、3个加分细节

  1. 用 emoji 分段：每行一个图标（🔹✨📮），手机上更清爽，不挤成一团；
  2. 留一句金句口号：让人记住你，比罗列成就更管用；
  3. 结尾加话题标签：如 #护肤 #成分党，强化赛道标签。
简介不是简历。别写「热爱生活、积极向上」这种谁都适用的空话——越具体、越像「一个人说的话」，越可信。

四、新手常犯的 3 个错

  • 太长像小作文：手机上翻三屏都看不完，直接划走；
  • 空洞没特色：和别人撞脸，记不住你；
  • 写了不更新：赛道转型了简介还停留在半年前，前后不一致掉信任。
